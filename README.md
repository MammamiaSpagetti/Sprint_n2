# Sprint_n2 — API-тесты сервиса «Доска»

API-тесты учебного сервиса [«Доска»](https://qa-desk.education-services.ru/).
Используются Python 3.10+, requests и pytest.

## Покрытие

| Модуль | Класс | Сценарии |
| --- | --- | --- |
| `test/test_registration.py` | `TestRegistration` | Регистрация с уникальным email; повторная регистрация с уже занятым email |
| `test/test_authorization.py` | `TestAuthorization` | Вход зарегистрированного пользователя и проверка выданного токена |
| `test/test_create_listing.py` | `TestCreateListing` | Создание объявления в категории «Книги» |
| `test/test_edit_listing.py` | `TestEditListing` | Изменение названия владельцем; запрет изменения другим пользователем |
| `test/test_delete_listing.py` | `TestDeleteListing` | Удаление своего объявления |

Всего **7 тестов**. Для операций с объявлениями проверяются HTTP-статус,
содержимое ответа и состояние данных отдельным GET-запросом.
После запрещённого редактирования проверяется, что исходные данные сохранились.

## Установка

Требуется Python 3.10 или новее. Команды для PowerShell выполняются
из корневой папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `py` отсутствует, для создания окружения используется
`python -m venv .venv`.

## Запуск

Все тесты:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Тесты выполняют запросы к учебному API и требуют доступа к интернету.

Запуск отдельной функциональности:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_registration.py
```

Запуск отдельного сценария:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_edit_listing.py::TestEditListing::test_another_user_cannot_edit_listing
```

## Тестовые данные

Фикстуры имеют область действия `function` и создают необходимые для каждого
сценария данные. Email генерируется с использованием UUID.
Для повторной регистрации используется email пользователя, созданного
в предусловии. Для проверки редактирования чужого объявления создаются
два пользователя.

После выполнения теста фикстура очистки удаляет созданное им объявление,
если оно ещё существует. Тестовые аккаунты остаются в учебной базе:
удаление пользователей требует прав администратора.

## Настройки

По умолчанию используется `https://qa-desk.education-services.ru/api`.
Для другого совместимого учебного стенда используется переменная окружения
`DESK_API_URL` с полным адресом API, включая `/api`.
Тайм-аут каждого HTTP-запроса — 30 секунд.

Пароль в `data.py` предназначен только для генерируемых тестовых аккаунтов.
Токены получаются во время выполнения и не записываются в файлы проекта.
